# CS50P - Introduction to Programming with Python

This repository contains my solutions to the problem sets and projects from Harvard University's **CS50P: Introduction to Programming with Python**.

The course covers the fundamentals of Python, from functions and variables to object-oriented programming and regular expressions, focusing on teaching how to solve problems with code.

---

## 📚 Course Content

| Week | Topic | Key Concepts |
| :--- | :--- | :--- |
| **0** | Functions, Variables | `print`, `input`, strings, integers, floats. |
| **1** | Conditionals | `if`, `elif`, `else`, boolean expressions. |
| **2** | Loops | `while`, `for`, `list`, `dict`. |
| **3** | Exceptions | `try`, `except`, `else`, `finally`, debugging. |
| **4** | Libraries | `import`, `sys.argv`, APIs, `random`, `statistics`. |
| **5** | Unit Tests | `pytest`, testing edge cases. |
| **6** | File I/O | Reading and writing `.txt` and `.csv` files. |
| **7** | Regular Expressions | `re` library, pattern matching, validation. |
| **8** | Object-Oriented Programming | Classes, methods, properties, inheritance. |
| **9** | Et Cetera | Set, Enumerate, Generators, Final Project. |

---
